# Friday, 7 August 2026

## Completed since the last stand-up

Worked on mobile push-notification integration and obtained/logged an Expo push token from the Pulse Guard application.

## Planned before the next stand-up

Use the registered token in the backend notification workflow and test whether incident alerts reach a physical device.

## Impediments, risks, or problems

Generating a push token does not demonstrate successful end-to-end notification delivery. Backend integration and physical-device testing remained outstanding.

## Reflection

Obtaining and logging an Expo push token showed that the app could register a device token, but it did not prove that an incident alert reached the device. I learned to treat token registration as one step in the workflow and to record a separate end-to-end test after connecting it to the backend.
